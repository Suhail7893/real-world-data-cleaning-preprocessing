# Real-World Data Cleaning and Preprocessing Using Python

## 📌 About the Project
A Python-based data cleaning project that uses the Hotel Booking Demand dataset to identify and handle missing values, remove duplicates, detect outliers, and preprocess categorical data.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- JupyterLab

## ✨ Key Features
- Missing value handling
- Duplicate removal
- Data standardization
- Outlier detection using IQR
- One-Hot Encoding
- Before-and-after data quality comparison
- Cleaned dataset export

## 📂 Project Structure

```text
Real_World_Data_Cleaning/

```

## 🚀 How to Run
```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyterlab
jupyter lab
```

Download the [Hotel Booking Demand dataset](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand) and place the CSV file inside the `data` folder before running the notebook.
